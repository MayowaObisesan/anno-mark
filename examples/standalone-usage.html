Annotation Editor Component - Standalone Example

About this Example

This demonstrates how the Annotation Editor component can be used in a standalone HTML file without any framework dependencies.

How to use:

  • Click "Start Annotating" to begin
  • Use the toolbar to select tools and colors
  • Draw directly on the canvas
  • Click "Export" to save your annotated image
